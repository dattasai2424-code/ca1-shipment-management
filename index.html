Quick Viva Question & Answer Reference

Q1: What is the main objective of your project?

To create a shipment management interface that provides continuous visibility into goods moving across supply chain stages and automatically detects bottlenecks when dwell time at warehouses exceeds the 18-hour SLA limit.

Q2: How does your bottleneck detection work in JavaScript?

In script.js, each shipment checks if its dwell hours exceed the SLA threshold (18h) or if an operational delay was logged. If true, the status becomes 'Delayed', the alert banner appears, and the milestone turns red.

Q3: How is data saved so that it is not lost on page reload?

Using the HTML5 localStorage API. Whenever a shipment is created, advanced, or updated, we call localStorage.setItem('logipulse_shipments', JSON.stringify(shipments)).

Q4: How did you implement the 5 transport milestones?

Through an array of 5 stages: Supplier Dispatched, In Transit Hub, Regional Warehouse, Out for Delivery, and Delivered. A numerical index (0 to 4) tracks progress, and clicking 'Advance Stage' increments this index and appends a timestamped checkpoint log.
